# Illustrated game assets

The owner approved the generated fixed-layout reference on 2026-11-08, including its graphics. Terrain and resource illustrations were generated for Game Shelf from that original concept using OpenAI image generation. No CATAN/OpenCatan artwork, external icon pack, downloaded font or third-party game asset was imported.

Terrain source: `exec-c3ac4e0b-363c-4db6-9af9-68a2a0f0eaa9.png`, a 1536 × 1024 six-cell atlas: grain, wood, ore, brick, wool, desert. Resource source: `exec-af8e24c4-6580-47e9-9570-9ed04f2c91ff.png`, a transparent 2172 × 724 five-icon sheet. Original outputs remain in the session's generated-image library. Committed WebP files are prepared derivatives: terrain cells at 512 × 512, resource icons centered on 144 × 144 transparent canvases. WebP encoding reduces download/cache size. These images contain no game state or number tokens.

The browser clips terrain images to real board hexagons and draws number tokens, roads, buildings, robber and port labels from authorized game state. Brand, pieces, port pennants and dice pips are original repository vector/CSS drawing. Georgia is requested as an installed system font; no font files are distributed. Generated art does not imply exclusive rights or affiliation with a commercial game publisher.
