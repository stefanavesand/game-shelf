Recover local games

If the app keeps asking for a compatible engine, you can abandon an old local test game here. This page loads outside the app’s offline cache.

Abandoning removes the game from your active list and releases its update pin. Its saved snapshot is kept. Your player identity, online games and other browser data are unchanged.

Use the same browser or installed app that holds the game. Close other game windows before continuing.
